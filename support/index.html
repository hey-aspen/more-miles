A run is missing

Open More Miles Settings, make sure Apple Health is connected, then sync. You can review permissions in Health → Sharing → Apps → More Miles.

Some metrics are unavailable

More Miles shows data associated with the activity in Apple Health. What is available depends on the recording device, granted permissions, and data saved by that activity.

Delete local data

Open More Miles Settings and choose Delete App Data. This removes local records while leaving original Apple Health workouts untouched.
